# PRD — 제품 요구사항 (에듀체크)

> 이 문서는 "무엇을, 왜 만드는가"에 답합니다. 근거 문서: IDEA.md

## 1. 목표
- 교육 프로그램 신청자 명단을 종이나 엑셀 대신 한 화면에서 관리한다.
- 행사 당일 참석 체크를 클릭 한 번으로 끝낸다.
- 프로그램별·참석 여부별로 바로 골라 볼 수 있게 한다.

## 2. 대상 사용자
- 교육기관 운영 담당자 1명 (v2.0부터 관리자 비밀번호로 로그인)
- 사용 환경: 노트북 또는 태블릿 브라우저 (최소 화면 너비 375px)

## 3. 기능 목록

| ID | 기능 | 버전 | 설명 |
|---|---|---|---|
| F-01 | 신청자 등록 | v0.1 | 이름, 연락처, 프로그램을 입력해 등록. 신청일은 자동 저장 |
| F-02 | 입력값 검사 | v0.1 | 이름 1~20자, 연락처 `010-0000-0000` 형식(숫자만 쳐도 하이픈 자동 입력), 등록된 프로그램 중 하나 |
| F-03 | 명단 보기 | v0.1 | 최신 신청순. 연락처는 가운데를 가려서 표시 |
| F-04 | 참석 체크 | v0.1 | 체크박스로 참석/미참석 전환, 참석한 행은 색으로 구분 |
| F-05 | 신청 취소(삭제) | v0.1 | 삭제 버튼 → 한 번 더 확인한 뒤 명단에서 제거 (실수로 지우는 것 방지) |
| F-06 | 인원 요약 | v0.1 | 화면 위쪽에 "전체 N명 · 참석 M명" 표시 |
| F-07 | 데이터 유지 | v0.3 | 새로고침하거나 서버를 다시 켜도 명단이 남아 있음 |
| F-08 | 중복 신청 막기 | v0.2 | 같은 연락처 + 같은 프로그램은 다시 등록되지 않음 |
| F-09 | 골라 보기(필터) | v0.4 | 프로그램별, 참석 여부별(전체/참석/미참석), 이름 검색 |
| F-10 | 신청자 정보 수정 | v0.4 | 이름, 연락처, 프로그램을 수정 |
| F-11 | 명단 CSV 내보내기 | v1.1 | 지금 화면에 보이는(필터된) 명단을 엑셀에서 열리는 CSV 파일로 저장. 파일에는 연락처 전체가 들어감 |
| F-12 | 프로그램별 요약 | v1.1 | 프로그램마다 "신청 N명 · 참석 M명"과 참석률(%) 표시 |
| F-13 | 프로그램 관리 | v1.2 | 프로그램을 화면에서 추가·수정·삭제. 이름, 기간(시작일·종료일), 장소, 정원을 정함. 신청자가 있는 프로그램은 삭제 불가 |
| F-14 | 정원 관리 | v1.2 | 정원이 찬 프로그램은 신청·이동을 막고 "마감" 표시. 요약에 "신청 7/10명" 표시. 정원을 신청자 수보다 적게 줄일 수 없음 |
| F-15 | 회차 관리 | v1.3 | 프로그램마다 회차를 날짜(와 메모)로 추가·삭제. 날짜순으로 1회차, 2회차… 표시. 같은 날짜는 한 번만 |
| F-16 | 회차별 출석 | v1.3 | 회차를 고르면 그 프로그램 신청자 명단이 나오고 출석 체크. 신청자별 "출석 2/3회", 회차별 "출석 4/5명", 프로그램 출석률 표시. 회차가 없는 프로그램은 지금처럼 명단에서 참석 체크 |
| F-19 | 수료 판정 | v2.1 | 프로그램마다 수료 기준 출석률(%, 기본 80)을 정함. 회차가 있는 프로그램에서 기준 이상 출석한 신청자에게 "수료" 표시. 요약 카드에 "수료 N명", 명단 CSV에 수료 칸 |
| F-20 | 회차 수정 | v2.1 | 회차의 날짜·메모를 고침. 출석 기록은 그대로. 같은 프로그램의 다른 회차와 날짜가 겹치면 막음 |
| F-21 | 출석표 내보내기 | v2.2 | 고른 프로그램의 사람 × 회차 출석표(O 표시, 출석, 출석률, 수료)를 CSV로 저장하거나 인쇄. 인쇄본은 연락처 가운데를 가림 |
| F-22 | 시연용 데이터 | v2.2 | 명령 하나(`uv run python -m app.seed`)로 가짜 프로그램·신청자·회차·출석을 넣음. 신청자와 회차가 하나도 없을 때만 동작 |
| F-23 | 회차 기간 검사 | v2.3 | 회차 날짜는 프로그램 기간 안이어야 함(종료일이 없으면 시작일 하루). 기간을 줄여서 기존 회차가 밖으로 나가면 막음. 날짜 칸도 기간 안에서만 고르게 |
| F-24 | 현장 체크인 | v2.4 | 태블릿용 큰 화면. 프로그램·회차(오늘 회차를 먼저)를 고르고 이름이나 연락처 뒷자리로 찾아 큰 버튼으로 출석. "출석 M/N명" 표시 |
| F-25 | 연락처 뒷자리 검색 | v2.4 | 명단 검색창에 숫자를 넣으면 연락처 뒷자리 4개로 찾음 (같은 이름 구분) |
| F-26 | 명단 일괄 등록 | v2.5 | 엑셀에서 이름·연락처 두 칸을 복사해 붙여 넣으면 줄마다 미리 검사하고 한 번에 등록(최대 200명). 실패한 줄은 이유와 함께 보여줌 |
| F-27 | 프로그램 복사 | v2.5 | 기존 프로그램의 장소·정원·수료 기준·기간을 새 프로그램 칸에 채움(이름 뒤 "(복사)"). 회차·신청자는 복사하지 않음 |
| F-28 | 통계 | v2.6 | 프로그램별 요약 표(신청·회차·출석률·수료)와 회차별 출석률 막대 |
| F-29 | 명단 파일 올리기 | v2.8 | 명단 한꺼번에 등록에서 엑셀(.xlsx)·CSV 파일을 고르면 이름·연락처를 읽어 붙여넣기 칸에 채움(검사·등록은 F-26과 같음). 머리글에 "이름"·"연락처(전화·휴대폰)"가 있으면 그 두 칸만, 없으면 앞의 두 칸. 첫 번째 시트만, 5MB까지. 숫자로 바뀌어 앞자리 0이 빠진 연락처는 되살림. 옛 엑셀(.xls)·암호 걸린 파일은 이유를 알려 줌 |
| F-17 | 관리자 로그인 | v2.0 | 관리자 비밀번호 하나로 로그인·로그아웃. 로그인은 12시간 유지, 브라우저 탭을 닫으면 로그아웃. 틀린 비밀번호를 1분 안에 5번 넣으면 1분 동안 로그인 막기 |
| F-18 | 명단 보호 | v2.0 | 로그인하지 않으면 명단·프로그램·회차·출석 API가 모두 거부됨(401). 로그인이 만료되면 로그인 화면으로 돌아감 |

## 4. 사용자 스토리
- 운영 담당자로서, 전화로 받은 신청을 바로 명단에 **등록**하고 싶다. (F-01, F-02)
- 운영 담당자로서, 같은 사람이 같은 프로그램에 **두 번 등록되지 않게** 하고 싶다. (F-08)
- 운영 담당자로서, 행사 당일 도착한 사람을 **체크 한 번으로 참석 처리**하고 싶다. (F-04)
- 운영 담당자로서, 지금 **몇 명이 신청했고 몇 명이 왔는지** 바로 알고 싶다. (F-06)
- 운영 담당자로서, 화면을 옆 사람이 봐도 **연락처 전체가 노출되지 않게** 하고 싶다. (F-03)
- 운영 담당자로서, 신청을 취소한 사람을 **명단에서 빼고** 싶다. (F-05)
- 운영 담당자로서, **모의면접 신청자 중 아직 안 온 사람**만 골라 보고 싶다. (F-09)
- 운영 담당자로서, 잘못 적은 이름이나 연락처를 **고치고** 싶다. (F-10)
- 운영 담당자로서, 명단을 **엑셀로 받아** 보고서나 출력용으로 쓰고 싶다. (F-11)
- 운영 담당자로서, **프로그램마다 몇 명이 신청하고 왔는지** 한눈에 보고 싶다. (F-12)
- 운영 담당자로서, 새 프로그램이 생기면 **코드를 고치지 않고 화면에서 추가**하고 싶다. (F-13)
- 운영 담당자로서, 강의실 자리보다 **신청을 더 받지 않게** 정원을 정해 두고 싶다. (F-14)
- 운영 담당자로서, 3일짜리 프로그램이면 **날마다 출석을 따로** 체크하고 싶다. (F-15, F-16)
- 운영 담당자로서, 수료 기준을 보려고 **신청자별 출석 횟수**를 알고 싶다. (F-16)
- 운영 담당자로서, 앱 주소를 아는 **다른 사람이 신청자 연락처를 보지 못하게** 하고 싶다. (F-17, F-18)
- 운영 담당자로서, **누가 수료 기준을 채웠는지** 바로 알고 싶다. (F-19)
- 운영 담당자로서, 일정이 바뀌면 **출석 기록을 잃지 않고 회차 날짜만 고치고** 싶다. (F-20)
- 운영 담당자로서, 보고용으로 **회차별 출석표를 엑셀이나 종이로** 받고 싶다. (F-21)
- 발표자로서, 시연할 때 **빈 화면 대신 그럴듯한 가짜 데이터**를 바로 보여주고 싶다. (F-22)
- 운영 담당자로서, 행사 당일 입구에서 **태블릿으로 이름이나 번호 뒷자리를 쳐서 바로 출석**시키고 싶다. (F-24, F-25)
- 운영 담당자로서, 구글폼으로 받은 **신청 명단을 한 번에 옮기고** 싶다. (F-26)
- 운영 담당자로서, 구글폼·엑셀에서 내려받은 **명단 파일을 그대로 올리고** 싶다. 복사할 칸을 고르지 않아도 되게. (F-29)
- 운영 담당자로서, 매달 같은 프로그램을 **설정 그대로 새로 열고** 싶다. (F-27)
- 운영 담당자로서, 회차가 지날수록 **출석이 줄어드는지** 보고 싶다. (F-28)

## 5. 범위 밖 (하지 않을 것)
IDEA.md의 "지금은 빼는 것"과 같습니다.
담당자 여러 명·회원가입, 공개 신청 페이지, 대기자 명단, 수료증 발급(수료 표시까지만),
문자·이메일 발송, 이메일·생년월일·메모 항목.
(로그인은 v2.0에서 범위 안으로 옮겼습니다. 비밀번호 1개만 씁니다.)

## 6. 화면 문구 (확정)

| 상황 | 문구 |
|---|---|
| 신청자 0명 | 신청자가 없습니다 |
| 필터 결과 0명 | 조건에 맞는 신청자가 없습니다 |
| 불러오는 중 | 불러오는 중... |
| 서버 연결 실패 | 서버에 연결할 수 없습니다. 서버가 켜져 있는지 확인해 주세요. |
| 삭제 확인 | {이름} 님의 신청을 취소할까요? |
| 이름이 비었을 때 | 이름을 입력해 주세요. |
| 연락처 형식이 틀렸을 때 | 연락처는 010-0000-0000 형식으로 입력해 주세요. |
| 중복 신청 | 이미 같은 프로그램에 신청한 연락처입니다. |
| CSV 버튼 | 명단 CSV 내보내기 (내보낼 사람이 0명이면 비활성화) |
| CSV 파일 이름 | 신청자명단_YYYYMMDD.csv |
| 정원 초과 | 정원이 가득 찼습니다. (정원 N명) |
| 프로그램 없음 | 먼저 프로그램 관리에서 프로그램을 추가해 주세요. |
| 프로그램 삭제 확인 | {프로그램 이름} 프로그램을 삭제할까요? |
| 프로그램 삭제 불가 | 신청자가 있는 프로그램은 삭제할 수 없습니다. |
| 같은 날짜 회차 | 같은 날짜의 회차가 이미 있습니다. |
| 회차 삭제 확인 | {N}회차({날짜})를 삭제할까요? 출석 기록도 함께 지워집니다. |
| 출석 기록 있는 신청자 이동 | 출석 기록이 있는 신청자는 다른 프로그램으로 옮길 수 없습니다. |
| 출석부 안내 | 회차를 추가하면 이 프로그램은 출석부에서 회차별로 출석을 체크합니다. |
| 로그인 화면 제목 | 관리자 로그인 |
| 비밀번호가 비었을 때 | 비밀번호를 입력해 주세요. |
| 비밀번호가 틀렸을 때 | 비밀번호가 맞지 않습니다. |
| 로그인 시도가 많을 때 | 로그인 시도가 너무 많습니다. 1분 뒤에 다시 시도해 주세요. |
| 서버에 비밀번호가 없을 때 | 서버에 관리자 비밀번호가 설정되지 않았습니다. backend/.env를 확인해 주세요. |
| 로그인이 만료됐을 때 | 로그인이 필요합니다. 다시 로그인해 주세요. |
| 서버가 3초 넘게 답이 없을 때 (v2.0.1) | 서버를 깨우는 중일 수 있어요. 무료 서버는 오래 쉬었다가 처음 접속할 때 1분 가까이 걸립니다. |
| 출석 기록 있는 신청자 수정 (v2.0.1) | 출석 기록이 있어 프로그램은 바꿀 수 없습니다. |
| 회차 추가 전 안내 (v2.0.1) | 참석 체크된 신청자가 N명 있습니다. 회차를 추가하면 명단에는 회차별 출석 횟수가 보이고, 기존 참석 체크는 출석 횟수에 들어가지 않습니다. |
| 수료 기준 범위 (v2.1) | 수료 기준은 1~100% 사이로 입력해 주세요. |
| 인쇄 창이 막혔을 때 (v2.2) | 팝업이 막혀 인쇄 창을 열 수 없습니다. 브라우저에서 팝업을 허용해 주세요. |
| 출석표 파일 이름 (v2.2) | 출석표_{프로그램 이름}_YYYYMMDD.csv |
| 회차 날짜가 기간 밖 (v2.3) | 회차 날짜는 프로그램 기간(2026.11.10 ~ 2026.11.12) 안이어야 합니다. |
