# PRD — 제품 요구사항

> 이 문서는 "무엇을, 왜 만드는가"에 답합니다. 근거 문서: IDEA.md

## 1. 목표
- 교육 프로그램 신청자 명단을 종이나 엑셀 대신 한 화면에서 관리한다.
- 행사 당일 참석 체크를 클릭 한 번으로 끝낸다.
- 프로그램별·참석 여부별로 바로 골라 볼 수 있게 한다.

## 2. 대상 사용자
- 교육기관 운영 담당자 1명 (로그인 없음)
- 사용 환경: 노트북 또는 태블릿 브라우저 (최소 화면 너비 375px)

## 3. 기능 목록

| ID | 기능 | 버전 | 설명 |
|---|---|---|---|
| F-01 | 신청자 등록 | v0.1 | 이름, 연락처, 프로그램을 입력해 등록. 신청일은 자동 저장 |
| F-02 | 입력값 검사 | v0.1 | 이름 1~20자, 연락처 `010-0000-0000` 형식(숫자만 쳐도 하이픈 자동 입력), 프로그램 4개 중 하나 |
| F-03 | 명단 보기 | v0.1 | 최신 신청순. 연락처는 가운데를 가려서 표시 |
| F-04 | 참석 체크 | v0.1 | 체크박스로 참석/미참석 전환, 참석한 행은 색으로 구분 |
| F-05 | 신청 취소(삭제) | v0.1 | 삭제 버튼 → 한 번 더 확인한 뒤 명단에서 제거 (실수로 지우는 것 방지) |
| F-06 | 인원 요약 | v0.1 | 화면 위쪽에 "전체 N명 · 참석 M명" 표시 |
| F-07 | 데이터 유지 | v0.3 | 새로고침하거나 서버를 다시 켜도 명단이 남아 있음 |
| F-08 | 중복 신청 막기 | v0.2 | 같은 연락처 + 같은 프로그램은 다시 등록되지 않음 |
| F-09 | 골라 보기(필터) | v0.4 | 프로그램별, 참석 여부별(전체/참석/미참석), 이름 검색 |
| F-10 | 신청자 정보 수정 | v0.4 | 이름, 연락처, 프로그램을 수정 |
| F-11 | 명단 CSV 내보내기 | v1.1 | 지금 화면에 보이는(필터된) 명단을 엑셀에서 열리는 CSV 파일로 저장. 파일에는 연락처 전체가 들어감 |
| F-12 | 프로그램별 요약 | v1.1 | 프로그램마다 "신청 N명 · 참석 M명"과 참석률(%) 표시 |

## 4. 사용자 스토리
- 운영 담당자로서, 전화로 받은 신청을 바로 명단에 **등록**하고 싶다. (F-01, F-02)
- 운영 담당자로서, 같은 사람이 같은 프로그램에 **두 번 등록되지 않게** 하고 싶다. (F-08)
- 운영 담당자로서, 행사 당일 도착한 사람을 **체크 한 번으로 참석 처리**하고 싶다. (F-04)
- 운영 담당자로서, 지금 **몇 명이 신청했고 몇 명이 왔는지** 바로 알고 싶다. (F-06)
- 운영 담당자로서, 화면을 옆 사람이 봐도 **연락처 전체가 노출되지 않게** 하고 싶다. (F-03)
- 운영 담당자로서, 신청을 취소한 사람을 **명단에서 빼고** 싶다. (F-05)
- 운영 담당자로서, **모의면접 신청자 중 아직 안 온 사람**만 골라 보고 싶다. (F-09)
- 운영 담당자로서, 잘못 적은 이름이나 연락처를 **고치고** 싶다. (F-10)
- 운영 담당자로서, 명단을 **엑셀로 받아** 보고서나 출력용으로 쓰고 싶다. (F-11)
- 운영 담당자로서, **프로그램마다 몇 명이 신청하고 왔는지** 한눈에 보고 싶다. (F-12)

## 5. 범위 밖 (하지 않을 것)
IDEA.md의 "지금은 빼는 것"과 같습니다.
로그인, 공개 신청 페이지, 프로그램 추가/편집, 정원·대기자·일정, 여러 회차 출석부,
문자·이메일 발송, 이메일·생년월일·메모 항목.
(로그인·프로그램 편집·정원·일정·회차 출석부는 로드맵 v1.2~v2.0에서 차례로 범위 안으로 옮깁니다.)

## 6. 화면 문구 (확정)

| 상황 | 문구 |
|---|---|
| 신청자 0명 | 신청자가 없습니다 |
| 필터 결과 0명 | 조건에 맞는 신청자가 없습니다 |
| 불러오는 중 | 불러오는 중... |
| 서버 연결 실패 | 서버에 연결할 수 없습니다. 서버가 켜져 있는지 확인해 주세요. |
| 삭제 확인 | {이름} 님의 신청을 취소할까요? |
| 이름이 비었을 때 | 이름을 입력해 주세요. |
| 연락처 형식이 틀렸을 때 | 연락처는 010-0000-0000 형식으로 입력해 주세요. |
| 중복 신청 | 이미 같은 프로그램에 신청한 연락처입니다. |
| CSV 버튼 | 명단 CSV 내보내기 (내보낼 사람이 0명이면 비활성화) |
| CSV 파일 이름 | 신청자명단_YYYYMMDD.csv |
