# 에듀체크 (EduCheck) — 교육 프로그램 신청·참석 관리 앱 아이디어

## 한 문장 정의
교육기관 운영 담당자가 쓰는 프로그램 신청자 명단 관리 웹 앱. 신청자를 등록하고, 당일 참석을 체크하고, 프로그램별로 골라 본다.

## 누가 쓰는가
- 운영 담당자 1명 (나). 신청자 본인이 직접 쓰는 화면은 없음.
- v2.0부터 관리자 비밀번호 하나로 로그인한다. (담당자 1명이므로 아이디·회원가입 없음)
- 행사 당일 노트북 또는 태블릿으로 참석 체크 → 목록이 한눈에 보이는 화면.

## MVP (꼭 필요한 것)
- 신청자 등록
  - 이름 필수, 1~20자 (앞뒤 공백 제거)
  - 연락처 필수, `010-0000-0000` 형식만 허용
  - 프로그램: 등록된 프로그램 중 하나 (처음에는 구직활동 프로그램 / 이력서 클리닉 / 모의면접 / 취업 특강, v1.2부터 화면에서 추가·수정)
  - 신청일: 등록 시각 자동 저장
  - 같은 연락처로 같은 프로그램에 두 번 신청할 수 없음
- 신청자 명단 보기 (최신 신청순)
- 참석/미참석 전환 (체크박스, 참석한 행은 색으로 구분)
- 신청자 삭제 (신청 취소)
- 새로고침해도 데이터 유지

## 지금은 빼는 것
- 담당자 여러 명, 아이디·회원가입, 변경 기록(누가 언제 체크했는지), 비밀번호를 화면에서 바꾸기 (비밀번호는 `backend/.env`에서 바꿈)
- 신청자가 직접 신청하는 공개 페이지
- 대기자 명단 (정원이 차면 신청을 막기만 함)
- 수료증 발급 (수료 여부 표시와 CSV까지만)
- 문자·이메일 발송
- 이메일, 생년월일, 메모 같은 추가 항목

## 개인정보 원칙
- 개발·배포 모두 가짜 테스트 데이터만 사용한다. (실명, 실제 전화번호 입력 금지)
- 연락처는 목록 화면에서 가운데 자리를 가린다. 예: `010-****-5678`

## 버전 로드맵

- v0.1 화면만 (브라우저 메모리)
- v0.2 API 연결 (FastAPI, 서버 메모리)
- v0.3 DB 저장
- v0.4 필터와 수정

  - 신청자 정보 수정

- v1.3 날짜별 회차 등록과 회차별 출석부, 출석률 계산
