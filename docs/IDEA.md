# 교육 프로그램 신청·참석 관리 앱 아이디어

## 한 문장 정의
교육기관 운영 담당자가 쓰는 프로그램 신청자 명단 관리 웹 앱. 신청자를 등록하고, 당일 참석을 체크하고, 프로그램별로 골라 본다.

## 누가 쓰는가
- 운영 담당자 1명 (나). 신청자 본인이 직접 쓰는 화면은 없음.
- 로그인 없음 (v2.0에서 추가).
- 행사 당일 노트북 또는 태블릿으로 참석 체크 → 목록이 한눈에 보이는 화면.

## MVP (꼭 필요한 것)
- 신청자 등록
  - 이름 필수, 1~20자 (앞뒤 공백 제거)
  - 연락처 필수, `010-0000-0000` 형식만 허용
  - 프로그램: 정해진 4개 중 하나 (구직활동 프로그램 / 이력서 클리닉 / 모의면접 / 취업 특강)
  - 신청일: 등록 시각 자동 저장
  - 같은 연락처로 같은 프로그램에 두 번 신청할 수 없음
- 신청자 명단 보기 (최신 신청순)
- 참석/미참석 전환 (체크박스, 참석한 행은 색으로 구분)
- 신청자 삭제 (신청 취소)
- 새로고침해도 데이터 유지

## 지금은 빼는 것
- 로그인, 담당자 여러 명
- 신청자가 직접 신청하는 공개 페이지
- 프로그램 직접 추가/편집 (정해진 선택지만 사용)
- 정원, 대기자, 일정(날짜·장소)
- 여러 회차 출석부
- 문자·이메일 발송, 엑셀 내보내기
- 이메일, 생년월일, 메모 같은 추가 항목

## 개인정보 원칙
- 개발·배포 모두 가짜 테스트 데이터만 사용한다. (실명, 실제 전화번호 입력 금지)
- 연락처는 목록 화면에서 가운데 자리를 가린다. 예: `010-****-5678`
